Economic order quantity, reorder point and safety stock

Find how much to order and when, so that ordering and holding costs balance and you hold enough safety stock for your service level.

Open the interactive calculator → Opens with the worked example already filled in, so you can compare your numbers against it.

How to use it

  1. 1Enter yearly demand, ordering cost per order and the holding cost per unit per year.
  2. 2Enter the supplier lead time and how much demand varies.
  3. 3Pick the service level you want to protect.
  4. 4Read the order size, how often to order, the reorder point and total cost.

Use it when: You are setting purchasing rules for tooling, inserts, raw material or spares.

How to read the result

  • Round the EOQ to a practical pack or pallet size; cost barely moves.
  • Safety stock rises with lead time, demand variation and service level. Shortening lead time is the best lever.

Formulas

  • EOQ = √(2·D·S / H)
  • Safety stock = z·σ·√LT
  • Reorder point = demand during lead time + safety stock
  • Cost = (D/Q)·S + (Q/2)·H

Watch out for

  • EOQ assumes constant demand and no quantity discounts.
  • Use the same time unit for demand deviation and lead time.

Source and basis

  • B.Tech: ET ZC343 Operations Management, lecture Ordering Quantities, and ET ZC416 Production Planning and Control, lectures on inventory (Sem VII).

ABC (Pareto) inventory classification

Rank items by annual usage value and split them into A, B and C classes so effort and control go where the money is.

Open the interactive calculator → Opens with the worked example already filled in, so you can compare your numbers against it.

How to use it

  1. 1List each item with annual demand and unit cost.
  2. 2Read the ranking with cumulative share of value.
  3. 3Items covering the first 80% of value are class A, the next 15% class B, the rest class C.
  4. 4Match control effort to class.

Use it when: Deciding which tools or parts to count often, stock tightly or put on vendor-managed supply.

  • Class A: tight control, frequent review, supplier partnership. Class B: normal control. Class C: simple rules, bulk buying, two-bin systems.

How to read the result

  • A short A class (often 10–20% of items) holding most of the value is normal.
  • High-value but critical C items still need a safety stock policy; value is not criticality.

Formulas

  • Annual value = demand × unit cost
  • Class by cumulative % of total value

Watch out for

  • Classify using at least 12 months of data.
  • Add a criticality flag (VED analysis) for items where a stock-out stops the line.

Source and basis

  • B.Tech: ET ZC343 Operations Management, lecture Ordering Quantities, and ET ZC416 Production Planning and Control, lectures on inventory (Sem VII). ABC classification follows standard Pareto inventory practice.

Demand forecasting (moving average and exponential smoothing)

Forecast next period demand from history, compare methods and see which one has the lowest error.

Open the interactive calculator → Opens with the worked example already filled in, so you can compare your numbers against it.

How to use it

  1. 1Paste or type your demand history, oldest first.
  2. 2Choose the moving-average window and the smoothing constant α.
  3. 3Read the next-period forecast from each method and their errors (MAD, MAPE).
  4. 4Use the lower-error method.

Use it when: Planning production, tools or staffing from past demand.

Worked example

Twelve months of demand with mild growth.

Show the input values used
  • Demand history (oldest first): M1 / 120; M2 / 132; M3 / 128; M4 / 140; M5 / 150; M6 / 147; M7 / 160; M8 / 158; M9 / 171; M10 / 175; M11 / 169; M12 / 182
  • Moving average window: 3.00 periods
  • Smoothing constant α: 0.300

  • Both methods lag when demand has a trend. For trending demand consider adding a trend term or a regression line.
  • Errors are compared over the same periods (after the moving-average warm-up).

How to read the result

  • MAD is the average miss in units; MAPE is the average miss in percent.
  • A very high α behaves like "last period"; a low α smooths noise but lags.

Formulas

  • MA: Fₜ = (Dₜ₋₁ + … + Dₜ₋ₖ) / k
  • ES: Fₜ = α·Dₜ₋₁ + (1 − α)·Fₜ₋₁
  • MAD = mean |D − F|; MAPE = mean(|D − F| / D)

Watch out for

  • Do not compare forecasts over different time spans.
  • Seasonality needs a seasonal method, not these.

Source and basis

  • B.Tech: ET ZC416 Production Planning and Control, forecasting lectures 3 and 4 (moving average, exponential smoothing, error measures).

Assembly line balancing

Group tasks into workstations to meet a target output, using the largest-candidate rule, and see efficiency and idle time.

Open the interactive calculator → Opens with the worked example already filled in, so you can compare your numbers against it.

How to use it

  1. 1Enter available time per day and the required output to get the takt (cycle) time.
  2. 2List tasks with time and predecessor (the task that must come first).
  3. 3Read the minimum stations and the assignment.
  4. 4Check efficiency and which station is the bottleneck.

Use it when: Designing or rebalancing a line, or testing whether a new task fits in the cycle.

Worked example

Nine tasks, 480 productive minutes per day, 110 units per day required.

  • Tasks (predecessor = task name that must precede, or blank): A / 2 / ; B / 1.5 / A; C / 3 / A; D / 2.5 / B; E / 1 / C; F / 3.5 / D,E; G / 1.5 / F; H / 2 / F; I / 1 / G,H

How to read the result

  • Any station near the takt line is the bottleneck. Stations far below it have slack you can use.
  • Efficiency = total work ÷ (stations × takt).

Formulas

  • Takt = available time / required output
  • Min stations = ⌈ Σ times / takt ⌉
  • Efficiency = Σ times / (n·takt)

Watch out for

  • A task longer than the takt cannot fit. Split it or duplicate stations.
  • Use realistic productive minutes after breaks and changeovers.

Source and basis

Project schedule: critical path (CPM and PERT)

Find the project duration, the critical path and the slack of each activity, with optional PERT three-point estimates.

Open the interactive calculator → Opens with the worked example already filled in, so you can compare your numbers against it.

How to use it

  1. 1List activities with predecessors.
  2. 2Enter optimistic, most likely and pessimistic durations (or the same value for a fixed time).
  3. 3Read the project duration and the critical activities.
  4. 4Check the probability of finishing by your deadline.

Use it when: Planning a launch, a trial, a shutdown or any project with dependencies.

  • Critical activities have zero slack: any delay moves the whole project.
  • The probability treats the critical path as normal (a PERT approximation).

How to read the result

  • Put your best people and attention on the critical path.
  • Activities with slack can start late without delaying the project, up to their slack.

Formulas

  • Expected time te = (o + 4m + p) / 6
  • Variance = ((p − o) / 6)²
  • ES = max EF of predecessors; EF = ES + te
  • LF = min LS of successors; slack = LS − ES
  • P(finish ≤ D) = Φ((D − T) / σ)

Watch out for

  • A second near-critical path can become critical when estimates move.
  • Resource limits are not in CPM: check the people and machines too.

Source and basis

  • B.Tech: ENGG ZC242 notes on CPM / PERT and ET ZC423 Essentials of Project Management.

Break-even and make-or-buy

Find the volume where revenue covers cost, or compare two options with different fixed and variable costs.

Open the interactive calculator → Opens with the worked example already filled in, so you can compare your numbers against it.

How to use it

  1. 1Enter fixed cost, variable cost per unit and selling price for option A.
  2. 2Optionally enter option B (for example outsourcing).
  3. 3Read the break-even volume and the volume where A and B cost the same.
  4. 4Compare with your expected volume.

Use it when: Evaluating a new line, a machine investment, or make versus buy.

Worked example

Make in house: $90,000 fixed and $6.50 per unit. Buy: $0 fixed and $9.00 per unit. Price $14. Expected 40,000 units.

Show the input values used
  • Selling price per unit: 14.00 $
  • A: fixed cost per year: 90,000 $
  • A: variable cost per unit: 6.50 $
  • B: fixed cost per year: 0 $
  • B: variable cost per unit: 9.00 $
  • Expected volume: 40,000 units/yr

  • Below the crossover the option with the lower fixed cost wins; above it the lower variable cost wins.

How to read the result

  • Margin of safety shows how far volume can fall before losing money.
  • A large fixed cost is fine if you are sure of the volume; otherwise prefer variable cost.

Formulas

  • Break-even = Fixed / (Price − Variable)
  • Crossover = (F_A − F_B) / (V_B − V_A)
  • Profit = (Price − V)·Q − F

Watch out for

  • Fixed costs are only fixed within a volume range.
  • Do not forget quality, lead-time and risk differences in make-or-buy.

Source and basis

  • Standard break-even and make-or-buy analysis (cost-volume-profit), as used in B.Tech ET ZC343 Operations Management and ET ZC423 Project Management.

Earned value: cost and schedule performance

Compare planned value, earned value and actual cost to get SPI, CPI and a forecast of the final cost and finish.

Open the interactive calculator → Opens with the worked example already filled in, so you can compare your numbers against it.

How to use it

  1. 1Enter the total budget (BAC).
  2. 2Enter planned % complete, actual % complete and the money spent so far.
  3. 3Read CPI, SPI and forecast cost.
  4. 4Compare against the rule thresholds.

Use it when: A project is mid-way and you need an honest status.

Worked example

A $500,000 project that should be 60% done is 50% done and has spent $330,000, with a 10-month plan and 6 months elapsed.

Show the input values used
  • Budget at completion (BAC): 500,000 $
  • Planned % complete: 60.00 %
  • Actual % complete: 50.00 %
  • Actual cost to date (AC): 330,000 $
  • Planned duration: 10.00 months
  • Time elapsed: 6.00 months

How to read the result

  • CPI and SPI below about 0.9 usually need a recovery plan.
  • A TCPI well above 1.1 means the original budget is no longer realistic.

Formulas

  • PV = BAC·planned%; EV = BAC·actual%
  • CPI = EV/AC; SPI = EV/PV
  • EAC = BAC/CPI; ETC = EAC − AC
  • TCPI = (BAC − EV)/(BAC − AC)

Watch out for

  • EV needs an honest measure of % complete; "90% done" is often optimistic.
  • SPI in money terms becomes unreliable near the project end.

Source and basis

  • Standard earned-value management practice, as in B.Tech ET ZC423 Essentials of Project Management.
